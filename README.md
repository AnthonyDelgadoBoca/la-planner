# Our Little LA Guide ♡

A romantic, mobile-first Next.js itinerary planner for October 23–November 1, 2026.

**Features:** shared password gate, signed session cookie, cloud-synced plan cards, add/edit/delete, image URL, time, location, external link, notes, search, iPhone-friendly layout, PWA manifest and Home Screen instructions.

See [SETUP.md](./SETUP.md) for database setup, environment variables, local development, deployment, and iPhone installation.
